# Fonts the templates use (all free, SIL Open Font License)
- Anton-Regular.ttf — tall condensed headlines (Cinematic template)
- Inter.ttf — clean sans for cards, kickers, chips (variable weight)
- NotoSansTamil.ttf — Tamil lines and voice captions (variable weight)

They are kept in the repository so every render uses exactly the same letters
(CLAUDE.md rule 2: same plan, same reel). Source: github.com/google/fonts (ofl/).
