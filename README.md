# iNiKKi Reels

A self-running Tamil cinema Instagram page (@inikki_reels).

**Start with `AGENT.md`.** It is the whole design in one file, including the copy-paste blocks to start the build and the Control Room.

- `niches/tamil-cinema/` — series, motion-graphics library, film bank, recommended-films log, sources, meme index
- `brands/inikki-reels/` — brand colours, fonts, image styles
- `rules/` — the playbook the agent learns into, and the change log
- `lab/` — ideas for new series
- `tools/` — the voice tool
- `engine/render/` and `templates/` — the reel maker: one plan file in, one finished, checked MP4 out (`templates/README.md`)
- `plans/` — one small plan per reel (examples in `plans/2026-11-13/`)
- `archive/v1/` — the earlier design, kept for reference
